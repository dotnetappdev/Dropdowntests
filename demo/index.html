Heavy load route

The picker opens and closes with the browser's built-in popover feature, so it needs no script. It uses the real restriction-picker.css from the repository, with Bootstrap 5 as in a new Visual Studio Web Forms project. The script at the bottom only pretends to be the server, so you can try it without running ASP.NET. The log shows what the code-behind would receive. Click Edit on a row to see the restriction as a dropdown in the grid row: it opens the full-screen list, with the row's Update and Cancel at the bottom.
